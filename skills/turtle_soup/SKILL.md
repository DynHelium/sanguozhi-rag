- 问能用 是 / 不是 回答的问题. 我答 是 / 不是 / 无关 / 无法判断.
- 想好了就输入 "/答 你的完整解释", 说到全部要点就算猜中.
- /提示 要一条提示, /放弃 揭晓汤底, /退出 结束游戏, /帮助 再看一遍玩法.
