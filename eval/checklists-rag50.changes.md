## 统一口径

- **core**：只标问题直接问的东西。问一件事 1 个 core；题干明确问两件（“是哪场战役？投奔者是谁？”“哪两个区域？为什么？”）各一个 core。
- **列举题**：题目明确列出要几项的（g-26 三国都城、h-01 多久/多少兵、h-03 关系/反应、p-01 三问），每一项都 core；题目只说“有哪些/分别”而 note 已说“答出 X 即对”的（h-27 两个赵达、h-31 两个文则），按 note：note 要求的项 core，note 说“只答一个算部分”的那一项不 core。
- **开放题 / 推断题**（hu-*、i-04/06/07/09）：core 是作者 ref 里的关键事实（1–2 项），价值判断、反事实、推测不进 must；“为何 / 该不该”的判断本身不判对错。
- **演义题（y-*）**：core = “点明是演义说法 + 正史对应记载”各一项；小说细节（性格冲突、西城、木像等）不进 must；“把演义当《三国志》记载”进 must_not。
- **must_not**：只保留回答里真会出现、且原文或题目说明能证伪的错误说法；泛化的“答成别人”只在有具体混淆对象（同名、同役）时保留；把史实或“出处标注不规范”列为 must_not 的删掉。
- **doubt**：只留需要作者定的问题；判卷提示写在本文件里。
