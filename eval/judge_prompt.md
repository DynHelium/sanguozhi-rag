# 判卷标准（给 AI 判卷模型看；流程见 `eval/ai_judge.py`）

目标：回答要答对，**不用特别严，但年份、事实不得说错**。

## 输入

`data/processed/eval_runs/judge/<名>/batchNN.json`：每题有问题、gold 段落（原文 + 白话）、各模型的回答，以及代码按年号表核对过的
"年号 → 公元年"（`year_checks`，`ok: false` 就是公元年写错了）。

## 怎么判

依据是《三国志》原文（`data/processed/sanguozhi.jsonl`，gold 段落已附上；回答里提到 gold 以外的事，用
`uv run python -m eval.find 词` / `uv run python -m eval.find --id 源id` 去原文核对）。唯一的例外是题目自带的参考答案：
官职地理题（geo）里原文没有、列在 `needs_reference` 的点按 `ref` 判，见下面"新题集"一节。不联网，不凭记忆裁定史实。

规则的优先级：题目自带的 `judge` 字段（这一题的判法说明）> 下面"新题集"一节的专项规则 > 本节的通用规则。

**计分范围**：题目明确要求的内容（包括官职地理题要的官职职能、今天的地名），不管写在回答的哪一段（正文或标明为背景的段落），
都按该题的参考答案和原文计分；题目没要求的额外背景常识（演义情节、官职地理常识）不计分，只在确知有误时记进 `bg_errors`。
但不管写在哪一段，和原文矛盾的具体史实（年份、人名、谁做了什么）仍算错（见下面"回答里标明为推断或背景的内容"）。

- **对**：答到了问题要的核心（要求列举的题要把 gold 里的各项都答到），说法和原文一致；**没有任何事实错误**。
  措辞、详略、多引几句原文都不扣分；补充的内容只要和原文不矛盾就行。
- **部分**：核心答到了，但漏了问题**明确要求**的某一项，且没有事实错误：问题要求列举（有哪些、有几个、分别、各自）却少列了一项，
  或问了两件事（"什么时候、做了什么"）只答了一件。
  "关系如何""经过如何""为什么"这类开放题，gold 只是参考要点：答到主要的方面、没有事实错误就算**对**，不因为没覆盖 gold 的每一段而判部分
  （见上面的目标：不用特别严）。
- **错**：核心答错、答非所问、空回答、有答案的题却说没找到；或者**有任何事实错误**：年份/公元年错（`year_checks` 里 ok 为 false 的一律算错）、
  人名指认错、官职/事件/因果和原文矛盾、把演义说成正史。原文没有、回答却说得很确定的具体事实（日期、数字、人名），在原文里查不到的也算错。
- 资料里本来就没有答案的题（gold 为空）：说《三国志》里没有记载 / 找不到就算对；编出答案算错。

**边界规则**（优先于上面"有任何事实错误算错"）：

- 答到了题目明确要求的核心，只是夹带了编造或张冠李戴的引文、出处或细节（题目没问的部分）→ **部分**；
  错误非常小（一个字、措辞、出处标错但引文和事实都对）→ **对**。核心答错、有答案的题说没找到因而没答出核心、公元年错、把演义说成正史，仍然算**错**。
- 资料里本来就没有答案的题，出题说明要求交代正史里的对应记载（如裴注引的说法和裴松之的驳斥）时，只说"没有记载"→ **部分**。
- 回答被截断，但截断前已给出核心结论 → 按已写出的内容判。

## 新题集（`type` 为 infer / yanyi / geo 的题，来自 `eval/questions-reason.jsonl`）的判法

这些题在包里会多出这些字段：`ref`（出题人给的参考答案）、`expect`（期望结论，常附推出它所依据的原文要点和源 id）、
`evidence`（推断题：出题人判断原文证据够不够推出结论，如 "够"）、`real` / `fiction`（演义题：
情节里正史有依据 / 原文没有或不符的成分，都带源 id）、`from_text` / `needs_reference`（官职地理题：原文能支持的部分 / 原文没有、
要按 `ref` 判的点）、`judge`（这一题的判法说明）。上面的通用规则照旧适用，另外：

- **infer（推断题）**：`ref` 是参考结论。答出 `ref` 的核心结论、推理所依据的事实和原文一致 → 对；结论对但推理里有事实错 → 错；
  `ref` 有几个要点（如"后方补给、退路、将士家属"），答到主要的就算对，不要求逐条。结论超出证据（把先后说成因果、把一种说法说成定论、
  把"没有记载"说成"没有发生"）→ 部分。只说"资料里没有直接记载"、不给结论，而资料里的事实足以推出结论 → 部分。
- **yanyi（演义题）**：**不要求答出小说情节**（`ref` 是小说里的答案，只用来认出问的是哪个情节）。判的是：有没有说清这个情节在《三国志》里
  是否有依据。对照 `real` 和 `fiction`：把 `fiction` 里的成分说成正史 → 错；把 `real` 里的成分说成虚构 → 错；说清了主要的真假（点出
  这是演义的说法，并给出正史里的对应记载）→ 对；只复述演义或只引正史、没有把两者对上 → 部分。题目里问小说细节的部分（计策名、
  天气、性格解读）答不答都不扣分，但答了就要说明是小说的说法。
- **geo（官职地理题）**：`from_text` 里的部分对照原文判；`needs_reference` 列出的点按 `ref` 判（原文没有，不要自己凭记忆另定答案）。
  和 `ref` 一致或意思相同 → 对；漏了 `ref` 的一项 → 部分；和 `ref` 或原文矛盾 → 错。

## 回答里标明为"推断"或"背景"的内容

- **标明为推断的**（如"据此推断"）：推理依据的事实要和原文一致；推断本身合理、没有越过证据就不扣分；越过证据 → 部分。
- **标明为背景、不是《三国志》记载的段落**（演义情节、官职地理常识）：题目没要求的部分不按原文核对，不计入对错
  （题目明确要求的官职地理内容写在这里，照样按该题的 `ref` 计分，见上面"计分范围"）；但你确知有误的（如把正史事件说成演义、
  把演义说成正史、地理常识说错且和 `ref` 矛盾），记进输出的 `bg_errors`。背景段里写了和原文矛盾的具体史实（年份、人名、谁做了什么）→ 错。
- **没有标明、却把原文查不到的事说得很确定** → 按通用规则算错（这一条不因为新题集而放松）。

## 输出

写 `batchNN.out.jsonl`（和包同名，一个回答一行，用 Python `json.dumps(..., ensure_ascii=False)` 写）：

```
{"model": "deepseek-v4.1-flash", "qid": "r-03", "verdict": "对", "errors": [], "comment": "答出建安七年至浚仪、治睢阳渠"}
{"model": "run1", "qid": "r-03", "verdict": "错", "errors": ["公元年写成 203（建安七年应为 202）"], "comment": "..."}
```

所有回答都另加三个字段（各题集都填）：

- `"fiction_as_fact": true/false`：回答有没有把《三国演义》或其他非正史的情节、说法当成正史叙述（点明了是演义说法的不算）。
- `"unsupported": []`：回答里说得很确定、但在原文里查不到的具体事实（年份、数字、人名、官职、谁说了什么、出处），每条一句，
  写清"回答说了什么、查了哪些词没找到"。查到原文支持的不写；和原文矛盾的只写进 `errors`，不写这里。标明为推断或背景、且没越过证据的不写。
- `"uncertain": ""`：拿不准怎么判时写一句原因（如"原文两种说法，回答取了一种"、"查不到这件事，不确定是不是编的"），
  先按你的最佳判断给 `verdict`；拿得准就留空字符串。

回答有没有引原文、标没标编号都不计分（有的回答不引原文）；只按内容判。

新题集的回答另加两个字段：`"yanyi_flagged": true/false`（回答有没有点明某个情节或说法出自《三国演义》，各类题都填）、
`"bg_errors": []`（见上）。

`errors` 只写事实错误和漏答的项，每条一句，写清"回答说了什么、原文是什么"，方便改进；没有就 `[]`。
