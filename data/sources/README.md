## 注意

- **“吴书”有两个**：《三国志·吴书》是三国志的一部分（层级 1）；韦昭《吴书》是东吴官修史，
  原书已佚，现存内容基本只见于裴注引文——它不单独成书，而是作为裴注的 `pei_cites` 标注。
  《魏略》《江表传》《汉晋春秋》《襄阳记》等同理。
- 层级只表示默认的取信顺序，不是绝对的。辅助史料成书晚于陈寿的（后汉书、晋书、通鉴）
  回答时要让用户知道成书年代。
- 古籍原文属公有领域，但**现代整理本的标点、校勘记可能受版权保护**（如中华书局点校本）。
  进仓库的文本优先用维基文库等明确自由授权的来源，并登记版本；来源不明的录入版不要提交。
- 无论哪个来源都要抽查错字和注文错位。
- 维基文库《三国志》注明「按中华书局 1982 年 2 版校对」，断句标点沿用点校本，所以仓库里只放去掉标点的白文，
  标点版由使用者自己从维基文库下载（`ingest.use_wikisource`，按 `raw/manifest.json` 的 revid，结果可复现）。
  白文的用字是解析时采用的读法，段落划分和源 id 与解析结果一致。
- 录入错误不改 raw，写进 `sanguozhi/patches.yaml`；补丁格式见 `ingest/wikitext.apply_patches`，已知问题见下。
